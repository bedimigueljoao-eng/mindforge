# MindForge v1.0

PWA instalável e offline.

## Publicar no GitHub Pages
1. Envie todos os ficheiros desta pasta para a raiz do repositório.
2. Em Settings > Pages, escolha Deploy from a branch, branch main e /(root).
3. Abra o endereço publicado no telefone e escolha Instalar aplicação.

## Estado desta versão
Funciona offline, guarda a biblioteca no dispositivo, apresenta dashboard, biblioteca, adição de conteúdo, leitura guiada, mapa, fluxograma, testes, aplicação, revisão, progresso e perfil. A IA real, extração de PDF, transcrição do YouTube e sincronização exigem um serviço seguro posterior. Nunca coloque chaves de API no app público.
